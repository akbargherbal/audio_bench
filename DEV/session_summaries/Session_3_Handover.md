## 5. Known Issues / Watch Points

- **Band energy thresholds need calibration:** The plan's heuristic thresholds (±0.10 low_mid, ±0.10 presence, ±0.05 high_shelf) were written before the normalization fix was known. With fractional values (0.170, 0.096, 0.018), ±0.10 may be too loose for high_shelf (its baseline is only 0.018). Flag during Phase 3 calibration pass — do not adjust before first real-chunk run.
- **Tempo reliability:** 112.5 BPM on Arabic poetry is almost certainly an artefact. Weight is 0.5 (lowest tier). Do not treat tempo delta as meaningful until confirmed against multiple chunks.
- **reference_profile.json is on disk** — `profiler.py` has a `load_reference_profile()` function. `main.py` should check for and use the cached file to avoid re-extracting on every batch run.
- **Threshold calibration pass is mandatory** after Phase 3 produces its first real-chunk report. Initial scores are heuristic — do not treat them as authoritative before calibration.
- **FR-8 Prompt Implication map** (Phase 5) — v1 mapping is defined in the plan. Do not implement until Phase 4 is signed off.
